Programa

? Sintaxis
INPUT
Dispositivos físicos de entrada.
INPUT SB1 SB2 SA3
Prefijo SB…
Pulsador momentáneo: activo solo mientras lo mantienes pulsado.
COIL
Bobina/salida gobernada por contactos.
COIL EL1 = SA1 AND !SA2
LATCH
Biestable con set y reset (auto-retención).
LATCH KM1 = SET(SB1) RESET(SB2)
TIMER
ONDELAY / OFFDELAY / PULSE, en segundos reales.
TIMER T1 = ONDELAY(KM1, 3)
AND OR !
Serie, paralelo, contacto NC.
(SA1 OR M1) AND !SA2
SET / RESET
Bobinas de asignación; pueden repetirse por nombre. Con ambas a la vez, manda la que va más abajo en el programa.
SET KM1 = SB1 RESET KM1 = SB2
P(...) / N(...)
Contacto de flanco: un solo ciclo al pasar de 0→1 (P) o 1→0 (N).
COIL PULSO = P(SB1)
COUNTER
CTU (ascendente) / CTD (descendente), cuenta flancos.
COUNTER C1 = CTU(SB1, RESET(SA1), 3)
TIMER FLASH
Relé intermitente con segundos ON/OFF propios.
TIMER LB1 = FLASH(KM1, 1, 1)
Prefijo ES…
Entrada que se dibuja como seta de emergencia.
SELECTOR
2 a 4 posiciones; crea NOMBRE_POSICION, solo una activa.
SELECTOR SW1 = MANUAL, PARO, AUTO
IMPULSE
Telerruptor: cada flanco conmuta el estado.
IMPULSE LB1 = SB1
Prefijos FT/QM/FU/QS/DIF
Iconos de térmico/magnetotérmico/fusible/seccionador/diferencial (solo visual).
POWERCHAIN
Circuito de potencia hasta un motor. Protección sana = conduce; contactor energizado = conduce. Si salta una protección, todo se congela hasta resetearla.
POWERCHAIN P1 = QM1 -> KM1 -> MOTOR M1
LINK / MOTOR
Como POWERCHAIN pero con ramas (cruces de fase, conexiones en estrella...).
LINK KM2 = a,b,c -> V1,U1,W1
INTERLOCK
Interbloqueo mecánico: solo el primer contactor de la lista cierra de verdad si piden los dos a la vez.
INTERLOCK KM1, KM2
PLC / EXPANSION
Modelo de autómata a dibujar (LOGO!/S7-1200) y módulos de expansión.
PLC S71200
LOAD / N / PE
LOAD = MOTOR para cualquier carga (monofásica incluida). N/PE siempre disponibles; fase+PE en un nodo = fuga a tierra real.
LOAD EL1 = b,N
